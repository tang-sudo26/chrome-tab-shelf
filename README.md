# TabShelf · 标签架

查资料、做方案或排查问题时，经常会开着几十个 Chrome 标签页。很多页面留着，是因为短期内还会反复访问，想用时能立刻切过去。可大量标签页持续打开，也会增加 Chrome 的内存占用。

TabShelf 让你在 Chrome 的新标签页里整理这些网址。把当前网页分类保存或拍成快照，再关闭暂时不用的标签。下次照常点 `+` 或按 `⌘T` / `Ctrl+T`，就能从收藏架单独打开一个网页，或勾选多个一起打开。收藏和快照保存在本机，重启 Chrome 后仍然可用。

## 快速安装

1. 在 GitHub 仓库点击 **Code → Download ZIP**，下载并解压。
2. 在 Chrome 打开 `chrome://extensions/`，开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选中包含 `manifest.json` 的文件夹。打开一个新标签页，即可使用 TabShelf。

项目无需安装依赖，也无需构建。更新代码后，在扩展程序页面点击 TabShelf 的「重新加载」，再刷新新标签页。

## 快速上手

- **收起一批网页**：点击「拍快照」，给手头正在用的页面勾选「留开」，再点击「保存并关闭」。
- **只存几页**：在「未上架」点击「多选」，勾选网页后选择「批量上架」或「上架并关闭」。
- **继续任务**：打开新标签页，在「收藏架」或某条「快照」里点开链接。想批量打开时，在「收藏架」先点「多选」，在快照详情可以直接勾选；选好后点击「打开所选」。

## 操作说明

- **布局**：点击页头的「切换布局」图标，选择「清爽启动页」（默认）或「紧凑工作台」。紧凑工作台在左侧显示工作区导航和分组，在链接旁显示域名；将鼠标停在域名上可查看完整网址。
- **外观**：两种布局都可以选「浅色」（默认）、「深色」或「跟随 Chrome」。「跟随 Chrome」使用浏览器为此页面报告的浅色或深色偏好（`prefers-color-scheme`）。所有视图和布局共用同一项外观设置。布局和外观分别保存在当前 Chrome 用户配置中，改动会同步到同一配置中已打开的 TabShelf 标签页，重开 Chrome 后也会保留。
- **网页搜索**：顶部「Chrome 网页搜索」使用 Chrome 的默认搜索引擎，结果在当前标签页打开。
- **收藏架**：清爽启动页可点击「分组」展开分类，点「全部」或收起分组即可回到全部收藏。分组右侧的「…」可打开或选中卡片显示的链接，也可查看该分类。点击「搜收藏」可按标题和网址跨分类查找，按 Esc 关闭并清除搜索。每条链接只属于一个分类，没有指定分类的链接放在「待分类」。点击标题可以打开链接；网页已经打开时，会跳转到现有标签页。清爽启动页的全部收藏下方会显示最多三条「最近使用」的收藏。
- **未上架**：按网站查看各普通窗口里还没收录的网页。可以逐个上架，或者在「多选」模式下跨域名、跨窗口勾选网页，也可以「全选当前列表」。批量操作使用同一个分类，默认「待分类」。「批量上架」会保留标签页，「上架并关闭」会在上架后尝试关闭所选标签页；结果会提示跳过或未确认关闭的数量。批量上架不会创建快照。已关闭、已上架或网址变更的标签页会从选择中移除；「退出多选」会清空选择并恢复逐页操作。
- **拍快照**：预览当前打开的网页并选择新链接的分类。选择「仅保存」可继续浏览；选择「保存并关闭」时，可以指定要留开的页面。已有链接保留原分类，所有预览中仍可保存的页面都进入快照，包括选择留开的页面。
- **快照**：按时间查找历史记录，点进快照后可以逐条打开，也可以勾选多个链接一起打开。快照和架子保存在当前 Chrome 用户配置中，退出并重新打开 Chrome 后仍可访问。
- **多选**：在收藏架点击「多选」显示复选框，然后勾选链接、点击标题切换选中状态，或用「全选当前列表」选中当前结果。切换分类或搜索时，已选链接仍保留。「清除选择」会清空勾选并留在多选模式；「退出多选」会同时清空勾选并隐藏复选框。收藏架和快照详情都可以「打开所选」；新标签页在后台打开，已打开的地址不会重复创建。
- **整理和删除**：链接右侧的「…」可移动到其他分类或删除该链接；「管理分类」可新建分类、删除当前分类或清空架子。进入多选模式后，还可以「删除所选」。清空架子会保留分类和快照；删除记录不会关闭已经打开的网页。

第一版管理普通窗口中的 HTTP 和 HTTPS 页面。Chrome 内部页面、扩展页面和无痕窗口不纳入快照，也不会被它关闭。快照保留页面标题和网址；从快照打开链接时会重新加载网页。数据只保存在本机的 Chrome 用户配置中。

## 手动验收

1. 在两个 Chrome 窗口打开几个不同的网页，并重复打开其中一个网址。打开 TabShelf 的「未上架」，将一个页面上架到新建分类。
2. 拍一份快照，选择保存并关闭，指定其中一个页面留开。验证快照包含所有网页、架子里没有重复网址、已有链接保留原分类，且只关闭未指定留开的网页。
3. 完全退出 Chrome，再重新打开并进入 TabShelf。确认分类、链接和快照仍在。从快照打开一条链接，重复点击时应复用现有标签页。
4. 在收藏架点击「搜收藏」，确认可直接输入，按 Esc 后搜索清空、焦点回到按钮。进入多选模式，用标题选中链接，切换分类后确认勾选仍保留，再退出多选并重新进入，确认没有选中项。
5. 用键盘打开链接的「更多操作」，选择删除再取消，确认焦点回到「更多操作」。用同一个菜单将链接移动到其他分类，确认链接出现在目标分类里。
6. 从「管理分类」清空架子，确认分类和历史快照仍在。已打开但不再上架的页面应重新显示在「未上架」。
7. 在清爽启动页按分组打开、选择或筛选收藏，确认可通过「全部」返回。搜索后再打开或选择分组，确认只影响卡片中显示的结果。打开几条收藏后，检查「最近使用」的顺序和点击行为；切换到紧凑工作台，确认左侧分类仍可用，且不显示「最近使用」。重新打开新标签页，确认布局和外观设置保留。
8. 在两个窗口打开不同域名的网页。在「未上架」开启多选，确认逐页操作隐藏、默认分类为「待分类」，且勾选前不能批量提交。跨窗口勾选，验证「全选当前列表」的部分选中状态；让一条已选标签页跳转到同域名的另一个网址，确认它不会继续被选中。分别试用两种批量操作，确认收藏进入所选分类、只在选择关闭时关闭标签页，且没有新快照。退出多选后确认逐页操作恢复，重新进入时没有勾选。
